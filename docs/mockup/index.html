Logo exploration

The first mark was a gradient square with a generic graph. These are seven different ideas. None uses a letter. Recommendation: A, “Landing”. A branch swings in and lands on main as a coral commit, under a HEAD ring. It reads as git at a glance, it is simple enough for 16px, and it owns a colour pairing (ink, teal, coral) that no other git client uses.

A · Landing recommended

A branch merges into main; the coral node is the commit that just landed. Ring on top is HEAD.

B · Check-in

A checkmark drawn as a branch with three nodes: committed, done. Friendly, but checkmarks are common.

C · Ship

Commits climbing to an arrow. Energetic, a little generic.

D · Braid

Two lanes crossing: merge as a weave. Distinctive, busy at small sizes.

E · Ring fork

A fork held in a ring: “commit to” as a promise. Strong silhouette.

F · Chat branch

Speech bubble with a branch: agents plus git. Clear idea, resembles a chat app.

G · Stack

Three commits stacked like layers. Memorable, but reads more like a database.
